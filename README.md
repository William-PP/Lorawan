# LoRaWAN

Repositorio para generar lecturas de sensores y comparar, sobre el mismo bloque,
tres formas de compresión: **Huffman**, **RLE** y **RLE → Huffman**. Mantiene las
salidas separadas por etapa y permite verificar los roundtrip sin modificar los
algoritmos.

## Documentación

- [docs/ARQUITECTURA.md](docs/ARQUITECTURA.md): comandos de terminal, estructura
  y decisiones técnicas.
- [salidas/README.md](salidas/README.md): convención de carpetas de salida.
